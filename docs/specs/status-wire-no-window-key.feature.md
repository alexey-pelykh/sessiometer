> beside a present `seven_day` window. Once the parser (#1596) and the reading model (#1597) serve
> that reply with its session window absent, the `status` reply and both `watch` frames carry
> `session_pct: null` for a healthy weekly-only account — the same bytes a failed poll produces,

> `blind_active` block at all under schema `1.14`, because `BlindActive.last_known_session_pct` is a
> `u8` (`src/daemon/snapshot.rs:167`) and the only value available would be a fabricated `0`. This
> item makes the wire say both in one `STATUS_SCHEMA_VERSION` minor: an omittable per-account key

> `last_known_session_pct` as an `Option<u8>` omitted when absent — the `rotated` reshape of `1.14`

> one new golden carrying both
> new states, the Swift mirror decoding both, the CLI reads of the reshaped field adapted, a
> non-inventing panel interim, a restored block that reads DEGRADED, never OK, once a session-less
> anchor is blind past the gate (#1599 § 2a — the duty #1602 hands this item; REQ-ARM-B-007), and the
> transitional `1.14` state (B-6t, decision D10) retired. It
> lands after the compile unit (#1596 + #1597 + block B-3) is on `main`; #1594 waits on its key.
